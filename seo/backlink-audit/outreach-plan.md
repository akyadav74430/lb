# Outreach Plan — LoveBite.live (Ethical, Manual, Free-Only)

## Principles

- **Manual and personalised.** Every message is written for one recipient.
  No bulk mail merge, no automated sending, no purchased contact lists.
- **Permission first.** Do not publish, quote, or link to a third party
  without their consent. For profile owners, link only when they opt in.
- **Disclosure.** Always disclose affiliation with LoveBite.live.
- **No paid link manipulation.** If a publisher requires payment for a
  placement, treat it as advertising and use `rel="sponsored"` (or `nofollow`)
  and comply with publisher and legal requirements. Do not buy links to
  manipulate rankings.
- **Approval gate.** No outreach is sent until the site owner approves the
  recipient list and message text.

## Target opportunity types (in priority order)

1. **Editorial mentions** — digital-safety, privacy, scam-awareness writers
   and regional journalists. Pitch the `/faq` safety resource, not profile pages.
2. **Resource pages** — "online safety", "privacy checklist", "scam awareness"
   resource lists that accept relevant, non-commercial resources.
3. **Legitimate directories** — established directories that accept this
   business type and provide genuine user value; follow their submission rules.
4. **Broken-link replacement** — only where the replacement page genuinely
   satisfies the original resource's purpose.
5. **Brand-mention correction** — if LoveBite.live is mentioned without a link,
   request a link politely and only with publisher permission.

## Pre-outreach checklist

- [ ] Confirm the destination page is indexable and useful (no thin/empty city
      pages). Link only to pages with real listings or the `/faq`.
- [ ] Verify the referring site's content is relevant and not a link farm/PBN.
- [ ] Record the opportunity in `competitor-analysis.csv` with evidence URL.
- [ ] Draft a personalised message using the templates below.
- [ ] Site owner approves recipient + message.
- [ ] Send manually from a real mailbox (support@lovebite.live or personal).
- [ ] Log outcome and date in `competitor-analysis.csv`.

## Recipient research (free, manual)

- Google operators: `intitle:resources "online safety"`, `"privacy checklist"
  resources`, `"scam awareness" India resources`.
- Read the target page fully; confirm it is editorial and has a genuine
  audience.
- Check the site's about/contact page for a named editor or writer.
- Check for a published editorial/advertising policy and respect it.

## Follow-up schedule

- Day 0: initial message.
- Day 7–10: one polite follow-up only (reply in same thread).
- Day 21: final check-in; if no response, mark as closed and do not contact
  again for at least 6 months.
- Never send more than two follow-ups per recipient.
- If a recipient asks not to be contacted, record and respect immediately.

## Tracking

Update `competitor-analysis.csv` for each opportunity:
- `verification_status` (contacted / replied / linked / declined / closed)
- `evidence_url` (the live linking page once a link exists)
- `checked_date`
- Notes on anchor text and link type observed.

## Safety notes

- Do not send outreach to sites that prohibit unsolicited contact.
- Do not misrepresent the site's verification capabilities.
- Do not request specific anchor text at scale; suggest natural anchors only.
- Do not exchange links or run reciprocal link schemes.
